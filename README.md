## What is this?

Personal brand hub and live portfolio for Naga Codex — four disciplines under one operator:

| Discipline | What ships |
|---|---|
| **AI Agents** | Production agent systems via Gemini API, Claude SDK, n8n, MCP |
| **Generative Film** | Text-to-video pipelines, sound design, cinematic grading |
| **Web & Product** | React 19 apps, serverless APIs, full-stack to Vercel |
| **Security** | Offensive audits, smart-contract reviews, cloud hardening |

No retainers. No middlemen. 20-min first call, free.

## Run locally

**Prerequisites:** Node.js 20+, pnpm

```bash
git clone https://github.com/Nagacash/nagacodex.git
cd nagacodex
pnpm install
cp .env.example .env.local
# add GEMINI_API_KEY to .env.local
pnpm dev   # → http://localhost:3000
```

```bash
pnpm build    # production build → dist/
pnpm preview  # preview the build
pnpm lint     # type-check
```
